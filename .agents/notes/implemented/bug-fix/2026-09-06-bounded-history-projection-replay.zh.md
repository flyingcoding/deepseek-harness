# Agent Note: 为有界冷历史提供完整投影

Status: implemented

[English](2026-09-06-bounded-history-projection-replay.md) | 中文

## 问题

冷历史窗口可能不包含选择模型或建立轮次大纲的事件。投影缓存缺失或版本不匹配时，即使可见消息已加载，模型选择器仍会一直等待。为了恢复这些值而激活 Agent，还会使单纯浏览保留完整 Session 日志。

## 决策

持久化窗口读取可以为返回窗口所属的完整已验证前缀提供 visitor。对于当前格式输入，JSONL 使用已发布 codec 确定精确继承切点，再次遍历同一份输入字节；第二次遍历仅保留一个事件，绝不打开完整日志句柄。历史控制器通过现有 restore 操作按页面大小分批计算所有已注册投影，并随打开快照发布完整基线。

visitor 不发布部分结果。取消、无效存储数据或投影失败都会拒绝读取。完整前缀回放也避免把过期 checkpoint 当作当前选择，或从不完整的可见尾部推导状态。较小或中断的日志保留普通的 prepared observation 路径。历史窗口读取使用读句柄迁移路径，不发布后继 generation；只有写 open 才发布当前 generation。

## 考虑过的替代方案

激活 Agent 来填充投影会为浏览操作保留完整 Session。仅计算可见尾部或信任旧 checkpoint，可能遗漏待生效的模型选择，并产生错误的轮次导航。完整前缀回放同时保留只读激活策略和完整投影语义。

## 后果

携带投影的当前格式 JSONL 窗口会解码输入两次，事件保留量受可见窗口、一个投影批次和一个解码事件约束。历史恢复可能在切片前物化完整的当前事件图；压缩输入字节、单个事件内容和投影状态各自有独立大小。这项成本保证完整投影语义，同时不激活 Agent，也不引入可能与追加竞争的第二次文件系统快照。

## 验证

存储测试覆盖明文与 Zstandard visitor、返回窗口之外的事件、精确 fork 元数据、取消和调用方失败。控制器测试在缓存缺失或过期时重建尾部之外的模型选择，同时禁止完整观察或激活。录制的 `seeded-history` 浏览器用例验证模型就绪、有界打开快照和向后翻页，且不创建 live Agent 或附加 Session。
